文本与图片 API

用项目的业务 API Key 调用火山方舟的豆包 Seed 文本与 Seedream 图片模型。

快速接入

  1. 登录客户工作台，在「API 接入」创建并妥善保存业务 API Key。完整 Key 仅在创建时显示一次。
  2. 将工作台提供的 API 地址设为 BASE_URL。以下示例直接拼接完整接口路径。使用要求 OpenAI 兼容基址的工具时，基址应为 $BASE_URL/v1。
  3. 发送 GET /v1/models 确认项目可用的模型 ID，再调用对应的接口。

模型接口通过 Authorization: Bearer <API_KEY> 鉴权。应用应从服务端环境读取业务 Key。

模型列表

GET/v1/models

从返回的 data 读取模型。id 用于提交请求，type 区分 text 和 image。

模型ID适用请求
豆包 Seed 2.1 Litedoubao-seed-2.1-lite日常对话、写作、摘要
豆包 Seed 2.1 Prodoubao-seed-2.1-pro复杂文本任务、代码
豆包 Seedream 5.5doubao-seedream-5.5文字与参考图生成图片
豆包 Seedream 5.0 Prodoubao-seedream-5.0-pro文字与参考图生成图片

文本对话

POST/v1/chat/completions

传入文本模型 ID 和有序的 messages。每条消息包含 role 和字符串 content，支持 system、user、assistant。多轮对话由客户端在每次请求中传入上下文。

从 choices[0].message.content 读取回复。usage 在上游返回时提供输入、输出与总 Token 数。

可选参数包括 temperature、top_p、thinking，以及 max_tokens 或 max_completion_tokens。最多发送 100 条消息，单条最多 32,768 个字符，请求 JSON 不超过 1 MiB。

设置 stream: true 可用 Server-Sent Events 逐段读取 choices[].delta.content。设置 stream_options.include_usage: true 可请求流末尾的计量信息。

图片生成

POST/v1/images/generations

必填 model 和 prompt。提示词最多 8,000 个字符。参考图通过 image 传入，可用一个公网 HTTPS 地址或最多 10 个地址组成的数组。

从 data[].url 读取图片地址。链接可能失效，需要保留时请及时下载。

可选参数包括 size（1K、1.5K、2K 或 宽x高）、output_format（png 或 jpeg）和 watermark。指定宽高时以相应模型的像素范围为准。

为每次新图片请求使用新的 Idempotency-Key。网络中断后重试时，沿用原幂等键和原请求体。

错误与重试

HTTP 状态处理方式
401核对请求头中的业务 Key，确认尚未撤销。
409检查幂等键是否已用于另一个请求，或原请求是否仍在处理。
422从模型列表选择对应类型的 ID，核对 JSON 字段和值。
429降低请求频率，等待后重试。
502 / 503服务可能暂时不可用。图片重试继续使用原幂等键。
