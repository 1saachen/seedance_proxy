Seedance API 开发者文档

用项目的业务 API Key 提交视频生成任务、查询结果及管理参考素材。

快速接入

  1. 登录客户工作台，在「API 接入」创建业务 Key。完整 Key 只在创建时显示一次。把它放在服务端环境变量 API_KEY 中。
  2. 把部署地址设为 BASE_URL，使用 Authorization: Bearer <API_KEY> 发起请求。提交 JSON 时设置 Content-Type: application/json。
  3. 创建任务并保存响应中的 id。用同一业务 Key 轮询任务，成功后读取 content.video_url。

业务 Key 用于视频和素材 API。项目的全部任务记录、账单和 Key 管理使用工作台登录会话。提交到真实方舟的生成任务可能产生费用。

方舟视频生成能力对照

创建视频任务

POST/api/v3/contents/generations/tasks

返回 HTTP 200 和 {"id":"vid_..."} 表示提交被受理。生成异步运行。提交前为这次请求设定 Idempotency-Key，可在断线后安全查询这次提交的结果。

字段类型用途与限制
model字符串，必填填写模型列表返回的业务别名。
content数组，必填至少一个输入项。提供提示词时最多一项 text。
resolution字符串按模型选择 480p、720p、1080p 或 4k。常规任务默认 720p。Draft 有单独的档位限制。
ratio字符串16:9、4:3、1:1、3:4、9:16、21:9 或 adaptive。2.5 系列的首尾帧、编辑和延长按输入适配比例。
duration整数输出时长（秒）。填 -1 由方舟选择。2.5 系列编辑设为 -1。
seed整数-1 随机取值，也可填写 0–2147483647。使用相同种子可以减少随机变化。
generate_audio布尔设置生成的视频是否带同步音频。
return_last_frame布尔开启后可从结果的 content.last_frame_url 取得尾帧。
watermark布尔控制输出视频是否带水印。
output_format字符串2.5 系列可指定 mp4 或 mov。使用 2.0 系列时省略此项，输出为 MP4。
draft布尔设为 true 生成 2.5 标准版样片。找出合适的样片后，可用该任务 ID 生成正式视频。
omni_reference_task_type字符串2.5 系列全模态任务意图。auto 由模型判断，reference 生成新视频，edit 编辑，extend 延长。
tools对象数组[{"type":"web_search"}] 允许模型按提示词决定是否搜索。
service_tier字符串支持在线推理 default。可以省略。
priority整数0–9，影响同一接入点的排队顺序。适用于 2.5 标准版与 2.0 系列。
execution_expires_after整数从提交起计算的超时秒数，3600–259200，方舟默认 172800。
safety_identifier字符串最多 64 个可见 ASCII 字符，用稳定的匿名值标识应用的终端用户。
callback_url字符串接收任务状态的公网 HTTPS 地址。详见回调参数与处理方法。

输入项 content

type数据字段位置或用途
texttext，最多 4000 字符描述构图、人物或物体动作、镜头、节奏、台词或声音。
image_urlimage_url.urlrole 可设为 first_frame、last_frame 或 reference_image（默认）。
video_urlvideo_url.urlrole 默认 reference_video。用于参考、编辑及延长。
audio_urlaudio_url.urlrole 默认 reference_audio。2.0 系列需同时提供参考图或视频。
draft_taskdraft_task.id填写同一业务 Key 生成成功的 2.5 样片任务 ID。从样片成片时只发送这一个输入项。

媒体地址可以是方舟可访问的公网 HTTPS 地址、处于 Active 的本站 asset:// 引用，或本站返回的预置素材引用。图片和音频也可使用 Base64 数据 URL，例如 data:image/png;base64,<BASE64>。JSON 请求最多 64 MiB，内联图片和音频解码后分别最多 30 MiB 和 15 MiB。需要传入较大的文件时，请先上传或使用公网 HTTPS 链接。

内联格式包括 JPEG、PNG、WebP、BMP、TIFF、GIF、HEIC、HEIF，以及 WAV 和 MP3。视频须使用 HTTPS 或素材引用。

方舟创建视频任务参数

生成方式与示例

把以下 JSON 作为创建视频任务的请求体。请将示例媒体地址和资源 ID 换成你自己的值。

首帧和首尾帧

指定一个 first_frame 可用该图起始生成。再提供一个 last_frame 可约束结束画面。首帧或首尾帧任务可提供提示词，搭配其它参考视频或音频时应使用全模态参考任务。2.5 系列的帧模式填写 ratio: "adaptive" 或省略比例。

全模态参考

把出镜角色、场景、动作和声音分别放到对应参考项，在提示词里说明每项的用途。2.5 系列可把 omni_reference_task_type 设为 reference 明确生成新视频。

视频编辑与延长

给 2.5 系列提交至少一个 reference_video，用 edit 编辑输入视频，用 extend 延长视频。两种方式的宽高比均随输入。编辑使用 duration: -1，作为编辑对象的视频时长须在 4–30 秒之间。2.0 系列在提示词中直接说明要变更或延长哪段视频。

用样片生成正式视频

  1. 选择 doubao-seedance-2.5，提交常规输入，并设置 draft: true 和 resolution: "480p"。
  2. 用创建样片的业务 Key 轮询，保存成功样片的本站任务 ID。当前创建的样片可在创建后 14 天内用于成片。
  3. 用同一业务 Key 创建成片任务。把原任务 ID 放入 draft_task.id，并指定 resolution 为 1080p 或 4k。成片自动继承样片的提示词、媒体、比例、时长、随机种子和音频设置。

联网搜索

给创建请求添加 "tools": [{"type":"web_search"}]，并在提示词中说明需要查询的当下信息。Seedance 2.0 系列使用联网搜索时只接受文本输入。查询成功任务时，从 usage.tool_usage.web_search 读取实际搜索次数。返回 0 表示模型未执行搜索。

查询与管理任务

查询单个任务

GET/api/v3/contents/generations/tasks/{id}

使用创建时的业务 Key 和本站返回的 vid_…。排队或运行中的任务会查询最新状态。终态任务返回已记录的结果。

结果可包含实际的 resolution、duration、ratio、output_format 与 framespersecond，以方舟实际返回为准。created_at 和 updated_at 为 Unix 秒。draft 标识样片，draft_task_id 指向本站样片任务。若发送了 safety_identifier，结果中的值为项目范围内的匿名摘要。

status客户端处理
submitting、queued、running等待并轮询，建议从 3 秒一次开始。批量任务应退避并避免同时轮询。
succeeded读取 content 和 usage。
failed、expired、cancelled停止轮询。核对错误或超时条件后，可按新的请求创建后续任务。
submission_unknown、submission_failed保存任务 ID。提交结果不明时用原幂等键核对，避免重复生成。

生成视频链接由方舟提供，有效期为 24 小时。需要留存视频时请在有效期内下载。任务记录和用量仍可查询，Richi Proxy 不会自动另存生成视频或延长链接。

查询任务列表

GET/api/v3/contents/generations/tasks

返回 {"total": …, "items": […]}，每项结构与单任务查询一致。查询范围是当前业务 Key 创建的任务，列表使用最近已记录状态。查询全项目时使用工作台的「任务记录」。

查询参数用途
page_num、page_size默认第 1 页、每页 20 项。两项均为 1–500。
filter.status按任务状态筛选。
filter.model按业务模型别名筛选。
filter.task_ids按本站任务 ID 筛选，可重复传入，最多 500 项。
filter.service_tier按服务层级筛选，查询参数接受 default 或 flex。本站新建 Seedance 2.x 任务使用 default。

取消或删除任务记录

DELETE/api/v3/contents/generations/tasks/{id}

排队任务可以取消，取消后可查询 cancelled 状态。运行中的任务返回 409 video_task_not_cancellable。成功、失败、超时或提交失败的任务可从任务查询和任务记录中删除，已产生的用量与账单仍保留。已取消的任务可通过 ?delete_cancelled=true 删除。成功操作返回 HTTP 200 和 {}。

收到 502 video_cancellation_unknown 时保留任务 ID，用单任务查询核对。结果含 cancellation_pending: true 时，方舟尚未确认取消。本站保留已有状态和用量，并避免重复发送取消请求。

上传与登记素材

有可访问的公网 HTTPS 地址时，可以直接登记。文件在本地时，先上传获得 uploadId，再用同一业务 Key 登记。登记时指定本站素材组和正确的媒体类型。

上传本地文件

POST/api/asset/upload-file

使用 multipart/form-data，必填 file，可选 assetType。系统按文件内容校验类型和大小。响应包含 uploadId、assetType、contentType、sizeBytes、status 与 UTC expiresAt。

assetType格式单个文件上限
ImageJPEG、PNG、WebP、GIF、BMP、TIFF30 MiB
VideoMP4、MOV200 MiB
AudioWAV、MP315 MiB

首次上传返回 HTTP 201。同一业务 Key 用原幂等键上传原文件时，已成功的记录返回 200。可用 GET /api/asset/upload-file/{uploadId} 查询暂存状态。文件默认暂存 48 小时，登记的素材由方舟处理。

创建素材组并登记

先调 POST /api/asset-group/create，请求体包含 name 和可选 description。从响应 group.id 取出本站素材组 ID。

POST/api/asset/create

已经托管在公网的文件可用 url 替换 uploadId，两者填写一项。登记成功返回 HTTP 201 和 asset.id。用同一 uploadId 重复提交等价请求可复用已登记的素材。若上游登记结果不明，先按错误码核对。

查询素材并用于生成

GET/api/asset/get?assetId={assetId}

素材可能为 Processing、Active 或 Failed。Active 时返回 asset.reference，可填入对应的 image_url.url、video_url.url 或 audio_url.url。上传记录按业务 Key 隔离，登记后的素材在所属项目内可用。用本站标识调用这些接口。

需要使用已获授权的真人肖像时，请先通过方舟授权流程创建对应素材组。

创建已授权的真人素材组

真人肖像授权由本人在方舟授权页完成。需要实例的方舟账号开通相应权益。

  1. 调用 POST /api/asset-group/liveness/start，提交 JSON {"callbackUrl":"https://example.com/consent-return"}。HTTP 201 返回 sessionId、authorizationUrl 和 expiresAt。在自己服务端保存会话 ID，并请本人在有效期内打开授权链接。
  2. 用户完成授权并回到你的 callbackUrl 后，接收方舟返回的 bytedToken。由你的服务端使用同一业务 Key 调用 POST /api/asset-group/liveness/complete，传入 {"sessionId":"…","bytedToken":"…"}。
  3. 方舟确认授权后，HTTP 200 返回 {group}，组类型为 LivenessFace。用返回的 group.id 登记已授权素材。尚未确认或会话过期时返回 409。

授权会话最长 180 秒。完成接口会向方舟核对授权结果，回跳参数中的 resultCode 只用于展示。使用同一业务 Key 和已成功的会话请求重试时，复用已创建的素材组。 方舟 H5 授权接口

GET/api/asset/presets

响应和普通业务请求使用同一 Bearer 鉴权。items 每项包含 id、name、assetType、reference。把返回的 asset://preset_… 填到对应的输入项。列表来自运营配置，尚未配置时返回空数组。 方舟 2.5 教程 · 角色参考

接收任务回调

在创建请求中填写可访问的公网 HTTPS 地址（端口 443，最多 2048 个字符），例如 https://example.com/events/video。Richi Proxy 观察到任务状态变化后，向 callback_url 发送 HTTP POST。JSON 正文结构与单任务查询一致，使用本站任务 ID。回调目标须直接响应，不跟随重定向。

任务排队、运行、成功、失败、取消和超时均可触发通知，提交失败或状态未知时也会通知。事件在同一任务内按顺序投递。连接失败或未收到 2xx 时，最多重试五次。重试间隔为 5 秒、30 秒、2 分钟、10 分钟和 30 分钟，队列执行可能延后。撤销业务 Key 会停止排队中的投递。也可用轮询补查结果。

请求头用途
X-Richi-Event-Id事件唯一标识，用于对重复投递去重。
X-Richi-TimestampUnix 时间戳，秒。用来检查签名时效。
X-Richi-Signaturesha256= 前缀和 HMAC-SHA256 十六进制摘要。

使用创建任务时的业务 Key 验证签名。以该 Key 的 SHA-256 二进制摘要作为 HMAC 密钥。签名输入由时间戳、圆点、事件 ID、圆点和原始正文按顺序拼接。验证后按事件 ID 去重，持久化结果后返回 2xx。

错误与重试

错误响应通常包含 detail.code 和 detail.message。需要保留任务或上传标识时，还可能返回 detail.task_id 或 detail.uploadId。

HTTP 状态与错误码处理方式
401 invalid_api_key检查 Authorization 格式、Key 是否撤销或复制完整。
404 video_task_not_found、asset_not_found、upload_not_found检查资源 ID、入口和所属项目。视频任务与上传记录必须使用原业务 Key。
409 idempotency_conflict、idempotency_key_conflict同一幂等键绑定了不同请求。原请求使用原内容，新任务或新文件使用新的幂等键。
409 video_submission_pending、502 video_submission_unknown保存任务 ID。用原幂等键和原请求核对提交，避免用新键立即发起生成。
409 video_cancellation_pending、502 video_cancellation_unknown取消结果待确认。稍后查询原任务状态，再决定是否重试取消。
404 video_draft_not_found、410 video_draft_expired使用同一业务 Key 下成功且仍有效的样片，或重新生成样片。
409 upload_registration_pending、upload_expired、asset_not_active登记待核对时保留上传 ID，过期后重新上传，素材处理中继续查询直到 Active。
409 asset_deletion_pending、502 asset_mutation_unknown素材变更结果待确认。删除请求可带原资源 ID 重试，确认删除后重复提交返回 204。
413 file_too_large、video_request_too_large、415 media_type_mismatch、422 invalid_request检查大小、编码、请求字段和模型能力，修改后再提交。
429 video_daily_limit项目每日提交上限已达。默认每项目 5 次，北京时间自然日计算。
502 video_status_unavailable、503 provider_unavailable查询按退避策略重试。有任务 ID 时查已有任务。服务未配置时联系运营核对。
503 video_callback_unavailable当前实例未开启回调投递。可省略 callback_url，通过查询接口跟踪任务。

幂等键支持 1–128 个可见 ASCII 字符。使用同一业务 Key 与幂等键重放相同请求，会复用原任务。一个新的业务请求使用新键。若网络中断需要跨进程重试，请先保存请求体和幂等键。

用量与账单

成功结果携带方舟返回的实际输出量 usage.completion_tokens。联网搜索次数单列在 usage.tool_usage.web_search，可按返回值做本地统计。未返回的用量保持缺失。

「用量与账单」按项目查看实际输出 Token 和费用。客户费用按约定模型、生成分辨率、是否含参考视频及有效价目计算。项目未开启计费时显示未计费，已开启但缺少计价资料时显示待计价。
