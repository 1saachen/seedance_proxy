接入火山方舟模型

把豆包 Seed 对话和 Seedream 图像生成接入你的应用。使用项目 API Key 调用，在工作台查看用量。

进入工作台 查看请求示例

从 API Key 开始

  1. 创建项目 API Key

    在工作台创建并保存业务 Key。

  2. 选择模型

    发送 GET /v1/models，从项目可用的模型中选择 ID。

  3. 发起调用

    调用文本或图片接口，读取返回的文本和图片地址。查看接入指南

请求示例

文本对话

curl "$BASE_URL/v1/chat/completions" \
  -H "Authorization: Bearer $API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "doubao-seed-2.1-lite",
    "messages": [{"role": "user", "content": "写一句海滨小镇的旅行推荐"}]
  }'

图片生成

curl "$BASE_URL/v1/images/generations" \
  -H "Authorization: Bearer $API_KEY" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $REQUEST_ID" \
  -d '{
    "model": "doubao-seedream-5.5",
    "prompt": "蓝调时刻雨后的海滨小镇，石板街上有一辆红色电车"
  }'

列出模型

curl "$BASE_URL/v1/models" \
  -H "Authorization: Bearer $API_KEY"
接入地址 站点 HTTPS 地址

接入常见问题

如何使用参考图生成图片？

在图片生成请求的 image 字段传入公网 HTTPS 地址。在图片生成文档查看参数。

在哪里查看调用用量？

登录工作台，在「用量与账单」按月查看项目的文本和图片调用记录。
