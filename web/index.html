Seedance 视频生成 API

接入火山引擎 Seedance。从服务端提交视频任务并查询生成结果，在工作台管理 API Key 和项目用量。

查看接入示例 创建账号

接入 Seedance

从服务器环境变量读取业务 API Key。

  1. 确认可调用模型

    在工作台创建 API Key，然后请求 GET /v1/models 查看当前可用的模型别名。

  2. 创建视频任务

    提交文本提示词。将一次业务请求绑定一个 Idempotency-Key，遇到断线时沿用原请求体与原幂等键。

  3. 查询结果

    使用创建任务时的 Key 查询 GET /api/v3/contents/generations/tasks/{id}。成功后可在链接有效期内下载视频。

常见接入问题

在哪里查看调用记录？

登录工作台，打开「用量与账单」，选择月份查看任务状态及返回的输出 Token。

怎样添加参考素材？

可以上传本地文件或登记公网 HTTPS 链接。素材状态变为 Active 后，把接口返回的 asset:// 引用传入生成请求。查看上传与登记步骤。
