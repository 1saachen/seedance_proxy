接入 Seedance

业务 API Key 只保存在你的服务器环境中。

  1. 确认可调用模型

    在工作台创建 API Key，然后请求 GET /v1/models 查看当前可用的模型别名。

  2. 创建视频任务

    提交文本提示词。将一次业务请求绑定一个 Idempotency-Key，遇到断线时沿用原请求体与原幂等键。

  3. 查询结果

    使用创建任务时的 Key 查询 GET /api/v3/contents/generations/tasks/{id}。成功后及时保存返回的视频链接。

常见接入问题

在哪里查看调用记录？

登录工作台，打开「用量与账单」，选择月份查看任务状态及返回的输出 Token。

怎样添加参考素材？

开通火山素材服务后，可通过 POST /api/asset/create 登记公网 HTTPS 素材链接。对处于可用状态的素材，可使用返回的 asset:// 引用提交视频任务。本地文件直传计划后续开放。
