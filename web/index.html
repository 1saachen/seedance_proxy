一句描述，
一段视频

用 Seedance 把提示词和参考素材变成视频。你可以在工作台体验生成，也可以通过 API 提交任务、查询结果。

进入工作台 快速接入指南

请求示例

创建视频

curl "$BASE_URL/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $API_KEY" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: $REQUEST_ID" \
  -d '{
    "model": "doubao-seedance-2.5",
    "content": [{"type": "text", "text": "日出时掠过海面的航拍"}],
    "duration": 5
  }'

列出模型

curl "$BASE_URL/v1/models" \
  -H "Authorization: Bearer $API_KEY"

查询任务

curl "$BASE_URL/api/v3/contents/generations/tasks/$TASK_ID" \
  -H "Authorization: Bearer $API_KEY"

从 Key 到生成结果

  1. 创建 API Key

    在工作台签发项目 Key。从服务器环境变量读取它，再通过 GET /v1/models 确认可用模型。

  2. 提交视频任务

    准备文本提示词或已登记的参考素材。遇到断线时，沿用原请求和原 Idempotency-Key 重试。

  3. 查询并下载

    使用原 Key 和任务 ID 查询状态，并在结果链接有效期内下载视频。

接入常见问题

在哪里查看调用记录？

通过「任务记录」查看项目任务。打开「用量与账单」可以按月查看任务状态和返回的输出 Token。

怎样添加参考素材？

可以上传本地文件或登记公网 HTTPS 链接。素材状态变为 Active 后，将接口返回的 asset:// 引用传入生成请求。查看上传与登记步骤。
