# Richi Proxy 首期工作计划

计划更新于 2026-11-26。原定 12 月 11 日交付试用、12 月 18 日完成首期闭环验收。RP-301 至 RP-303 已暂停，后续排期待确认。真实联调取决于下文列出的外部条件。

## 开发基线

当前仓库已有客户注册、登录和独立项目，支持业务 Key 创建与撤销、国内 Seedance 2.0／2.5 的异步创建与查询、项目日提交上限及后台任务补查。客户可登记服务器暂存文件或公网 HTTPS 素材、查询处理状态并引用本项目归属明确的素材。客户工作台可查看本项目记录和实际返回的输出 Token。公开首页已有 canonical 和站点地图的生成入口，需配置正式站点地址。 [本地运行和现有接口](../README.md)

## 第 1 周 · 11 月 30 日至 12 月 4 日

主线是本地文件上传、服务器暂存及素材隔离。先完成服务端上传和登记，再用客户 API 示例跑通全流程。上传、查询和生成引用均由客户通过 API 完成。

| 编号 | 工作与负责职能 | 验收 | 依赖 |
| --- | --- | --- | --- |
| RP-101 | 后端负责人接入 `multipart/form-data` 上传，检验真实媒体类型与大小，按项目和业务 Key 创建暂存记录，并把文件写入服务器暂存目录。 | 合法图片、视频和音频可获得本项目 `uploadId`。损坏文件、类型不符、超限和存储失败有明确结果，重试及清理可追踪。 | 本地验证使用临时目录和临时 SQLite。生产需可持久化的暂存目录。 |
| RP-102 | 后端负责人接通暂存文件登记和素材引用。登记核对项目、业务 Key、文件类型、素材组及上传消费状态，为方舟提供有限期的取件链接。 | 上传文件可登记并轮询至 `Active`，再用于本项目视频。跨项目和同项目其他 Key 的上传记录访问被拒绝。重复登记和上游结果未知时保护记录，避免清除可能已被引用的文件。原有 URL 登记通过回归。 | RP-101。真实联调需方舟可访问的公网 HTTPS，素材与推理 Key 的上游项目须一致。 |
| RP-103 | 客户端协助者更新工作台 API 接入示例，测试协助者并行验证客户从命令行调用的完整流程。 | 使用客户业务 Key 通过 API 跑通「上传 → 登记 → 查询可用 → 引用」。第二个客户只能查到和使用自己的素材。失败响应能定位出错环节。 | RP-101／102 的接口契约。 |

## 第 2 周 · 12 月 7 日至 11 日

主线是客户用量计价、月账单冻结和火山成本对账。先固定计量及金额口径，再为运营内测交付账单与差异查询。

| 编号 | 工作与负责职能 | 验收 | 依赖 |
| --- | --- | --- | --- |
| RP-201 | 后端负责人落地逐调用真实用量归集、经核实的 Seedance 价目版本和项目折扣。 | 每笔成功调用可追溯到任务、实际 Token、计价条件、单价和折扣。金额按十进制计算并以整数微元持久化。缺少用量或价目进入待计价，重复查询只归集一次。 | 方舟实际用量样本和适用价目。 |
| RP-202 | 后端负责人接入北京时间月度预估、运营确认冻结和客户账单明细。客户端协助者提供项目范围内的显示与导出。 | 可核对本月预估和正式账单。冻结后原金额和明细保持稳定，迟到用量有归属和调整记录。跨项目账单读取和导出均被拒绝。 | RP-201 与业务方确认的账期、折扣、舍入和税费口径。 |
| RP-203 | 对账协助者与后端负责人接入火山成本账单导入，提供去重、汇总及差异报告。 | 同一官方账单样本重复导入只有一份有效明细，可还原同口径总额和已知差异。按官方可用维度匹配，无法逐笔关联时保留未匹配项。火山实付与客户应付分别展示。 | 火山脱敏账单样本、账单读取权限和可关联字段。 |
